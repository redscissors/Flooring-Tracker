P1Schluter configurator

Kits · Custom shower · Browse — same shell as wedi, with the Source switch in the header. Everything below is live: click around.

What's Schluter-specific

  • The walls are a fork, not a given. wedi walls are always wedi panel. Schluter walls are either KERDI-BOARD (foam board, like wedi) or KERDI membrane over backer (backer by others) — different bills, different labor. The Custom tab makes it a first-class choice and the build column regroups around it.
  • Trays cut, they don't extend. wedi solves rooms with extensions; Schluter's answer is the next tray up cut down (soft 6″ rule kept) or a mortar-bed fallback card.
  • No published-retail rule yet. wedi's Builder = retail × 0.82 is a wedi program. Schluter pricing here shows Retail / Builder −8% as the app default — the real rule is an open question for the owner.

P2Stock only / Full catalog

The same 38″×60″ curbed build rendered under each source mode — this is one popup with the header switch flipped, shown twice.

How the switch behaves

  • Full catalog (default): the solver ranks freely; a line the shop doesn't stock wears the rust special order tag and the build column's stock meter says how much of the bill ships from the shelf.
  • Stock only: non-stocked parts leave the candidate pool entirely — kits gray out, option cards re-rank, and where a stocked substitute exists the build swaps to it (larger tray cut down, 108 sf KERDI rolls instead of the 323 sf roll). A line with no stocked substitute stays, flagged, so the build is never silently wrong.
  • It's a shell feature. The switch lands in the shared popup header, so wedi gets it for free the same day — wedi's Browse tab already ranks stock first; this makes it a hard constraint when you want one.

P3wedi ⇄ Schluter compare

One room in, two systems out. Pick a preset room; both engines build their house kit and the grid lines them up by category.

Data status — what to upload

  • Schluter catalog & net cost: the current Virginia Tile Schluter EFT (SLR_EFT_*.xls — the 7,033-row one from issue 083, or newer). The import pipeline already parses every Schluter size spelling; the configurator engine would be generated from it like wedi's was.
  • Stock flags & shop retail: the shop's Schluter_stock sheet (107 items, "updated 4.30.2024" — a current export) and/or the ERP Vendor SKU Analysis for Schluter, to mark what's on the shelf and price it.
  • System recipes: the Schluter Illustrated Price List / Shower System brochure PDF, to transcribe kit contents and coverage rules the way wedi's handbook rules were transcribed.
  • Every price on this page marked est. is a placeholder at plausible MAP — good enough to judge the UI, not good enough to quote from.

Three ways to ship "compare" — recommendation

  • A. Compare tab (this prototype): a fourth tab in whichever configurator is open — runs the other engine on the same room. Salesman-facing, zero new data model.
  • B. Cross-price chip: lighter — the build column footer shows "≈ $1,9xx in Schluter — open", jumping to the other popup with the room carried over.
  • C. Quote options (already shipped, ADR 0031): customer-facing — land the wedi build in Option A and the Schluter build in Option B of the same area; the estimate prints both prices side by side with zero new print work.
  • Recommendation: A + C. A is where the salesman decides; C is how the customer sees it. B falls out of A almost for free later.
