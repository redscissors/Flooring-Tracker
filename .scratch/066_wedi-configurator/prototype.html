nedwedi shower-system configurator — interactive prototype

Issue 066 · One popup, three surfaces. wedi is the opposite of Sheoga on both axes: every piece has a part number and wedi publishes suggested retail — so nothing is marked up. Sell is book retail, cost is distributor net (≡ the ERP's stocked cost), and Builder is the one wedi-specific rule: retail × 0.82. What replaces Sheoga's description builder is a system solver — a shower is a pan + extensions + panels + curb + drain finish + consumables that all have to agree. Everything on this page runs live off proto-engine.js (115 self-test assertions) over the real Jan 2026 pricelist + ERP stock export.

Vendor configurators
How it triggers: a token completing toward “wedi”, a strong word (fundo, curbless, riolito, shower pan, niche…), or a weak trade word beside a size. A parsed size opens the room solver pre-filled; kit words open the kit cards; a named part opens the catalog. Unrelated trade queries (“porcelain 12x24”, “schluter reducer”) never pin the row. In production this recognizer is the only wedi code on the boot chunk (wediquery.js, a few hundred bytes) — the tables stay inside the lazy popup chunk (ADR 0026).
Prototype notes.
  • Kits — every stocked pan is a card; one click assembles the house kit (pan · ½" panels for the picked walls · curb lean / curbless waterproofing · drain cover · fasteners · sealant · collars · trowel) mirroring wedi's boxed recipe, with the factory-kit compare chip under the totals.
  • Custom room — the solver returns ranked options (exact pan · pan + extensions with the corner rule · larger pan cut down · linear module + extension), each with a to-scale top-down layout and an isometric view; Print produces the installer layout sheet.
  • Browse — the whole catalog, stock ranked first, group chips + search + steppers, and the sealant/fastener figurer using wedi's own planning rates (1 screw+washer / ft² · 1.2 oz / ft²).
  • Port to project — “Add to product lines” previews the exact payload rows: the pan line carries wedi:{mode,cfg} for the Reconfigure chip, companions carry wedi:{part:true}, stocked lines key the ERP SKU, and every line carries the ×0.82 Builder stamp in tierPrice.
