Label maker overhaul: three takes

All three keep the dark card exactly as it looks today. The changes in the grey box below come with every take. The takes differ only in where the template settings live and how the screen is laid out.

Pin to bottomA template can pin lines (e.g. Grout) to the bottom of the card. They stay there however much text sits above.
Name auto-shrinksIf a long name would run into the pinned lines, the name's font steps down until it fits. The preview tells you when it has shrunk.
Save up topSearch, New and Save Label sit together in the top bar: search, adjust, save, and never scroll.
Label set fixedSaved cards are left-aligned like the preview and the print. Today they're centred because each card sits inside a button.
Everyday form = text + nudgesOnly the text boxes and a −/+ font nudge per line. Size, header, order, show/hide and pinning move into the template.

A · Template bar with a fold-down editor

Recommended

One top bar holds everything you touch every time: which template, the stock search, New, Save. Edit template folds a drawer open right under the bar with size, header, lines and pinning. Close it and it's out of the way. It changes the current screen the least, so the team won't have to relearn much.

+ Everyday screen is as short as it gets
+ Template edits show live in the same preview
− The drawer pushes the form down while it's open

B · Two tabs: “Labels” and “Templates”

Making labels and designing templates become separate screens. The Labels tab has just the template picker, search, form and preview. The Templates tab is a full-width editor with a big preview. This is the cleanest split, but checking a layout change against a real label means switching tabs.

+ Cleanest everyday screen, and the editor gets room
+ Good home for a template list (rename / delete)
− One extra click to tweak a template mid-label
