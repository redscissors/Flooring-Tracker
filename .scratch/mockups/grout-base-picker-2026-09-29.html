Grout base picker

Pick the base right in the row's grout pop-up. The project remembers your grout and base for the next row. Extras adds it all up at the end. Clickable, not wired to anything; prices are sample numbers.
Try it: open a row's extras, tick Grout, pick SpectraLock Pro, then change the Base dropdown next to the joint width. Then tick Grout on another row: it starts on the same grout and base. Color is never carried over. Change the sq ft and watch the base count in Extras follow. New project goes back to the standard defaults.

How the base adds up: each row only says which base it uses. Extras totals the kits per base across the whole job, then divides by what one unit covers. So 5 kits of Bright White and 3 of Natural Gray on Commercial = 8 kits ÷ 4 = 2 Commercial units, whatever the colors. Change a tile's sq ft later and it re-figures on its own; nothing needs re-swapping.
Settings: a grout can hold several bases. The ★ one is the standard default a new project starts on. The rest show up in the row's Base dropdown. Each base says how many color kits one unit covers (Full = 1, Commercial = 4, Sanded/Unsanded = 1). A grout with only one base shows no dropdown at all.
