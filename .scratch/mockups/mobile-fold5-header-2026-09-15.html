Every phone is 344 CSS px wide (the Z Fold 5 cover screen, 904 × 2316 at ~2.63×, ≈ 344 × 882). The green ruler (measured in a real browser, not estimated) marks how much of the screen the header stack takes before the first area starts.

All three drafts drop the Edit / Print preview tab row on mobile (Print stays in the bottom bar and the ⋯ sheet; the option menu's "Print this option…" still works — it opens the print view directly) and replace the scrolling stat strip with the desktop one-bar's vocabulary: sand band, bordered id boxes, eyebrow-over-value, segmented price level, bordered minis.
