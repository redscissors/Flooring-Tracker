Run it like this

  1. Open a throwaway order in the ERP — one you can delete, so nothing real gets keyed.
  2. Reorder and rename the fields above until they match the entry screen left-to-right.
  3. Hit Copy test line, click into the first field of an empty entry line, paste.
  4. If nothing moves, also try pasting with the line selected as a row (some grids only take a paste on the row, not in a cell), and try right-click → Paste.
Result A

It jumped across the fields

The SKU, description and qty each landed in their own field. The ERP takes tab-delimited paste — FloorTrack alone can do this with a copy button on every special-order line. No extra software needed.

Result B

Everything landed in one field

The ERP treats a paste as plain text, so the tabbing has to be real keystrokes. Same copy button in FloorTrack, plus a tiny free helper (AutoHotkey) on the order-desk PC: one hotkey types each field and presses Tab between them.
